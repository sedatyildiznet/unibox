# Product Features

Unibox aims for a familiar power-user universal-inbox experience while remaining an independent product.

## Inbox

Unified inbox, multiple accounts per network, pins, archive, unread, mentions, drafts, groups, account/network filters, favorites/labels, muted/low-priority chats, fast global search, keyboard navigation and a command palette.

## Messaging

Connector-driven support for text, attachments, media, replies, reactions, edits/deletes, read receipts, typing, threads, stickers/GIFs and other primitives where each remote network supports them.

## Productivity roadmap

Send Later, chat reminders/snooze, repeat notification for unread chats, unified media/files/links views, local full-text search and contact-identity suggestions.

## Account management

Add, rename, pause, reconnect and remove accounts; show health/reauthentication state; label connectors as Candidate, Beta or Experimental until they pass stability tests.
