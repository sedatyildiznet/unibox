# Release Acceptance Criteria

A stable Windows release is not ready until a clean Windows machine can install Unibox without manual Docker/YAML/Matrix steps; connect at least two accounts where supported; restart Windows and recover sessions; send/receive common text/media actions; detect broken connections; update and roll back a connector safely; update the desktop app through a signed release; export redacted diagnostics; and perform tested backup/restore without credential leakage.

No connector is marked Stable merely because it starts once.
