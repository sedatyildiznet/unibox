# Roadmap

## Foundation

- local-first desktop shell
- managed WSL2 runtime
- Synapse and PostgreSQL provisioning
- connector registry and adapters
- signed desktop updater architecture

## Messaging reliability

- production connector login flows
- multi-account validation
- unified inbox normalization
- reconnect and recovery handling
- connector update rollback

## Desktop quality

- notifications and tray behavior
- global search
- storage controls
- backup/restore
- diagnostics
- installer polish

## Later scope

Voice/video calls, mobile clients, cloud sync and team/multi-user hosting are intentionally outside the first stable desktop release.
