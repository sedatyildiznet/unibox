# UX direction

Unibox uses a familiar universal-messenger structure without copying another product's branding or exact interface.

## Desktop layout

The primary desktop view uses three functional regions:

1. A compact service/account rail for All, service filters, account access and settings.
2. A conversation list with search, unread/mention filters, service badges and account context.
3. The active conversation with message history, replies, reactions, attachments and a capability-aware composer.

## Familiar interaction patterns

Users coming from modern desktop messengers should immediately understand:

- unified inbox
- unread and mention views
- per-service/per-account filtering
- global conversation search
- account connection health
- native desktop notifications
- tray/background operation
- keyboard-focused navigation

## Unibox identity

The visual design should remain dark-first, restrained and content-focused. Third-party service colors should appear primarily in icons and small identity indicators rather than dominating the interface.

## Capability awareness

The composer and message actions must adapt to the active connector. Features such as edits, reactions, polls, threads, voice notes and read receipts should only appear when the remote network and connector support them.
